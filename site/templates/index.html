Three properties that decide quality

Energy and money are never floats

Every OICP number is an exact decimal. No public field of any wire type is an f32 or f64, the sync engine has none either, and a repository check enforces it in CI.

OICP defines ConsumedEnergy as MeterValueEnd − MeterValueStart. In f64, 10.1 − 0.1 is 10.000000000000002.

Numbers and money →

Identifiers are never rewritten

Every OICP identifier accepts two grammars — ISO 15118 and DIN SPEC 91286. This crate parses both, exposes the country and operator, compares them semantically, and writes back the exact text that arrived.

Hubject matches the identifier in your URL against your TLS certificate as text. A library that normalises DE*ABC to DEABC earns a 017 on every request.

Identifiers →

Parsing and conformance are separate

One operator's malformed HotlinePhoneNumber cannot make a page of two thousand EVSE records undecodable. The value arrives; validation reports it with an RFC 6901 JSON Pointer.

Parse permissively, validate explicitly, construct strictly.

A brokering system, in a process

Testing against the real thing needs a signed contract, certificates from Hubject's CA, and access to their QA environment — weeks before the first request. And the failures that cost time are sequences, not single messages.

MockHubject routes the way the real broker does, tracks sessions, and answers with the specification's own status codes. Offline, in a unit test.

What is in the box

Transport

The endpoint table — service × version → path — the page envelope, and the error mapping that makes HTTP 200 mean success.

Client

Mutual TLS with a local certificate check, streaming crawls, and retries that will not start a session twice.

Server

The half Hubject calls, which most implementations skip. One trait per role; if it compiles, your surface is complete.

Delta sync

The LastCall engine, with a property test proving any delta sequence converges on a full pull.

CDR pre-flight

The calibration-law and plausibility rules, checked before submission rather than weeks later in a dispute.
